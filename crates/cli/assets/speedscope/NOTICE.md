# speedscope

The files of this directory are the release build of
[speedscope](https://github.com/jlfwong/speedscope) 1.21.0 (see `release.txt`), © Jamie Wong,
distributed under the MIT license (`LICENSE`). They are not modified. The font they use, Source
Code Pro, is distributed under the SIL Open Font License (`source-code-pro.LICENSE.md`).

speedscope is the viewer `shopify theme profile` opens. `lsf` embeds it to show the profile
of a page as a flame graph: `/__lsf/profile?path=<path>&html=1`. The example profile of the
release (`perf-vertx-stacks-01-collapsed-all.txt`) is left out. The two licenses are served
with the viewer: `/__lsf/speedscope/LICENSE` and `/__lsf/speedscope/source-code-pro.LICENSE.md`.
